# Recruiter Screen

The recruiter checks basic fit, logistics, pay range, and whether the candidate can explain the move clearly. Answers stay short (20 to 45 seconds).

## Themes for the question bank

Background and fit to the role. Why this company. Why leaving the current role. Logistics (location, work mode, notice, work authorization). Comp. Process and other interviews.

## Round section: `## Recruiter screen essentials`

1. **Comp script.** If the JD posts a range, quote it with the source. Script: first deflect ("I'd like to learn more about the scope first. What range is budgeted for this role?"), then, if pressed, give a range. Use `[your target range]` unless the user gave a number in this thread or in career facts. Never invent a number.
2. **Logistics.** Location comes from the contact line of the master resume. Work mode, notice period, and work authorization come only from the sources. Otherwise use `[your notice period]` or `[your work authorization status]`.
3. **Why leaving.** Forward-looking: what the candidate wants next and how this role offers it. Never negative about the current employer.
4. **Timeline.** A neutral line about other processes, with `[other processes, if any]`.
